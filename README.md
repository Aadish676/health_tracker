# Health Tracker

Track meals, workouts, sleep, body weight, goals, and community progress in one place.

## Live app

**[Open Health Tracker](https://health-tracker-ten-lac.vercel.app)**

## Project links

## Technology

- React and Vite frontend
- FastAPI backend
- Neon PostgreSQL for deployed data storage
